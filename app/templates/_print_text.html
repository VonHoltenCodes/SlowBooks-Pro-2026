{# The one rule for text on a printed page, taken into every printed template's style block: a word longer than the room it has breaks inside the word, so text never widens its column and nothing is laid out past the page margin. A word breaks between words only, and inside when it alone is longer than its line (break-word). A word of 20 characters or more (a web address, a reference, a name typed with no spaces) is set in a .long-word element by the renderer (pdf_service.break_long_words), on every printed page, and may break at any character: it never holds a column or a row open. A description that has only the room the other columns leave it (td.desc.squeeze) may break inside any word. What must keep its width says so where it is styled: figures, dates and labels are white-space: nowrap, and a column of short text beside a description has a width of its own. #} html { overflow-wrap: break-word; } .long-word { overflow-wrap: anywhere; } .long-word-gap { display: inline-block; width: 0; } /* a figure is on one line */ td.r, td.num { white-space: nowrap; } /* a unit a person typed beside a quantity, when it is a long one, wraps in a width of its own */ td.r > .unit { display: inline-block; max-width: 1.2in; white-space: normal; overflow-wrap: anywhere; vertical-align: top; } /* The heading row of a page: the title is a label and keeps its width; the block beside it has the rest, and a long name or address wraps there without squeezing or pushing the title. */ .header { column-gap: 16px; } .header > :first-child { flex: 1 1 0%; min-width: 0; } .header > :last-child { flex: none; } .header h1 { white-space: nowrap; } /* a document's number, and what a person typed beside the dates, wrap in a width of their own; a date stays on one line */ .invoice-number, .doc-number { max-width: 3.4in; margin-left: auto; } .meta-table td.text { white-space: normal; max-width: 260px; }
